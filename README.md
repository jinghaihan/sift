# Sift

Review a feature branch without the unrelated changes merged in from its integration branch.

A native desktop app built with [MyGo](https://github.com/egoist/mygo). Read the complete feature diff, leave comments on lines, and keep track of reviewed files.

## Develop

Requires Go 1.27.2 or later and Git 2.36 or later.

```sh
go tool mygo dev
```

## Build

```sh
go tool mygo build
```
