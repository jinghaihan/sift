# Sift identity

- `sift-concept.png`: the original approved design board, preserved unchanged.
- `../../resources/icon.png`: the standalone app icon, with transparent space around the charcoal tile. MyGo generates the platform icon sizes from this PNG when building the app.

The mark combines a custom S silhouette with a sage-green connection representing the selected feature branch. The board includes the wordmark and small icon previews.

Created with the built-in image generation tool. The production export used the approved board as its reference with this instruction:

> Extract the large left app icon faithfully, preserving its symbol, colors, material, proportions and internal spacing. Remove the wordmark, previews and presentation background. Center the rounded tile on a square transparent canvas with equal padding.

The PNG is the production source. No editable vector source is currently available.
